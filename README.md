# dotfiles

Personal Linux desktop dotfiles managed with [GNU Stow](https://www.gnu.org/software/stow/).
Each top-level directory is a Stow package that mirrors paths under `$HOME`.

## Packages

- `hypr` - Hyprland, Hypridle, Hyprlock, Hyprpaper, wallpaper cycling, and related user services.
- `kitty` - Kitty terminal settings.
- `nvim` - Neovim configuration based on Kickstart with custom language, AI, notebook, Markdown, and LaTeX tooling.
- `rofi` - Rofi app/file launcher and calculator styling/scripts.
- `swaync` - SwayNotificationCenter configuration and styling.
- `waybar` - Top notch-style Waybar, popup helpers, and user service.
- `zsh` - Zsh shell setup.

## Install

Install Stow first, then clone this repository to `~/dotfiles`:

```sh
git clone <repo-url> ~/dotfiles
cd ~/dotfiles
```

Stow the packages you want:

```sh
stow hypr kitty nvim rofi swaync waybar zsh
```

To install one package at a time:

```sh
stow nvim
```

To remove symlinks for a package:

```sh
stow -D nvim
```

If Stow reports conflicts, move or back up the existing files in `$HOME` before running the command again.

## Dependencies

Install the tools for the packages you use. This setup references:

- Desktop: `hyprland`, `hypridle`, `hyprlock`, `hyprpaper`, `waybar`, `swaync`, `rofi`, `rofi-calc`, `kitty`, `zsh`
- Utilities: `stow`, `fzf`, `zoxide`, `yazi`, `wl-clipboard`, `ffmpeg`, `systemd`, `hyprpolkitagent`
- Desktop helpers: `chromium`, `blueman-manager`, `nm-connection-editor`, `pavucontrol`
- Neovim: `neovim`, `git`, `ripgrep`, `fd`, `make`, `gcc`, `unzip`, `tree-sitter`, plus the language tools described in `nvim/.config/nvim/CONFIG.md`

## Notes

- The Hyprland config currently targets monitor `HDMI-A-2` at `3440x1440@100`; adjust `hypr/.config/hypr/hyprland.conf` for other displays.
- Waybar theme colors are generated by `hypr/.config/hypr/wallpaper-cycle.sh` in `$HOME/.local/state/waybar/tahoe-colors.css`.
- Neovim-specific details live in `nvim/.config/nvim/CONFIG.md`.
